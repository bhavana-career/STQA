# Master Test Case Specification — Student Result Management System (SRMS)

All test cases below are automated and verified in the Pytest suite (`tests/`).

| Test ID | Feature | Preconditions | Test Steps | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|---|
| **TC-001** | Marks Validation (Valid Boundaries) | `marks_service` loaded | Call `validate_subject_mark` with `0, 1, 34, 35, 49, 50, 59, 60, 69, 70, 79, 80, 84, 85, 89, 90, 100` | Returns integer mark without error | Returns integer mark without error | **PASS** |
| **TC-002** | Marks Validation (Negative Marks) | `marks_service` loaded | Call `validate_subject_mark(-1, "Physics")` | Raises `MarksValidationError` ("cannot be negative") | Raises `MarksValidationError` | **PASS** |
| **TC-003** | Marks Validation (Above 100) | `marks_service` loaded | Call `validate_subject_mark(101, "Mathematics")` | Raises `MarksValidationError` ("cannot exceed 100") | Raises `MarksValidationError` | **PASS** |
| **TC-004** | Marks Validation (Empty / Missing) | `marks_service` loaded | Call `validate_subject_mark("")` and `validate_subject_mark(None)` | Raises `MarksValidationError`; never silently converts to `0` | Raises `MarksValidationError` | **PASS** |
| **TC-005** | Marks Validation (Decimals & Invalid Types) | `marks_service` loaded | Call `validate_subject_mark(75.5)`, `"85.5"`, `True`, `"abc"` | Raises `MarksValidationError` | Raises `MarksValidationError` | **PASS** |
| **TC-006** | Total Marks Calculation | 6 valid subject marks `[92, 88, 95, 96, 85, 90]` | Call `calculate_total_marks(marks)` | Returns `546` | Returns `546` | **PASS** |
| **TC-007** | Percentage Calculation & Rounding | Total marks `412` out of `600` | Call `calculate_percentage(412)` and `format_percentage()` | Returns `68.67` and `"68.67%"` | Returns `68.67` and `"68.67%"` | **PASS** |
| **TC-008** | Individual Subject Grading Matrix | Marks across all 8 grade bands | Call `calculate_subject_grade(m)` for `100, 90, 89, 85, 84, 80, 79, 70, 69, 60, 59, 50, 49, 35, 34, 0` | Returns `O, O, A+, A+, A, A, B+, B+, B, B, C+, C+, C, C, F, F` | Exact grade match for all 16 boundary points | **PASS** |
| **TC-009** | Overall Classification (All Subjects Passed) | All 6 subjects `>= 35` | Call `determine_classification(pct, True)` for `75.0, 74.99, 60.0, 59.99, 50.0, 49.99, 35.0, 34.99` | Returns `Distinction, First Class, First Class, Second Class, Second Class, Pass, Pass, Fail` | Exact classification match | **PASS** |
| **TC-010** | Critical Single-Subject Fail Rule | 5 subjects `= 100`, Mathematics `= 34` (Total `534/600`, `89.00%`) | Call `evaluate_student_result(marks)` | `overall_status = "FAIL"`, `classification = "Fail"`, `failed_subjects = ["Mathematics"]` | Overall result is `FAIL` with `89.00%` displayed | **PASS** |
| **TC-011** | Teacher Login (Valid Credentials) | Application running | POST `/login` with `teacher01` / `Teacher@123` | Redirects to `/teacher/dashboard` with session role `teacher` | Redirected to `/teacher/dashboard` (`200 OK`) | **PASS** |
| **TC-012** | Student Login (Valid Credentials) | Application running | POST `/login` with `student01` / `Student@123` | Redirects to `/student/dashboard` with session role `student` | Redirected to `/student/dashboard` (`200 OK`) | **PASS** |
| **TC-013** | Invalid Login Rejection | Application running | POST `/login` with invalid password or empty fields | Returns HTTP `401` with clear error banner on login page | HTTP `401` and error alert displayed | **PASS** |
| **TC-014** | Role Access Restriction (Student $\rightarrow$ Teacher Route) | Logged in as `student01` | GET `/teacher/dashboard`, `/teacher/students`, `/teacher/marks`, `/teacher/analytics` | Backend returns HTTP `403 Forbidden` | HTTP `403 Forbidden` returned on all teacher routes | **PASS** |
| **TC-015** | Student Record Isolation | Logged in as `student01` (`STU001`) | GET `/student/view/STU002` | Backend returns HTTP `403 Forbidden` | HTTP `403 Forbidden` returned | **PASS** |
| **TC-016** | Unauthenticated Route Protection | Logged out session | GET `/teacher/dashboard` and `/student/dashboard` | Redirects (`302`) to `/login` | HTTP `302` redirect to `/login` | **PASS** |
| **TC-017** | Student CRUD — Create & Duplicate Check | Logged in as `teacher01` | Create `STU050`, then attempt to create `STU050` again | First creation succeeds and persists to JSON; duplicate is rejected with error flash | Created once; duplicate rejected | **PASS** |
| **TC-018** | Student CRUD — Search & Section Filter | Logged in as `teacher01` | GET `/teacher/students?q=Kiran` and `/teacher/students?section=B` | Returns matching students only | Matching students rendered | **PASS** |
| **TC-019** | Student CRUD — Update & Delete | Logged in as `teacher01` | Edit `STU050` details/section, then POST delete | Record updated in JSON, then permanently removed from JSON | Updated and deleted accurately | **PASS** |
| **TC-020** | JSON Persistence Across Restart | Teacher creates `STU077` (`neha77`) | Instantiate new Flask app pointing to same JSON file; log in as `neha77` | `neha77` logs in and views `420/600` (`70.00%`, `First Class`) | Persisted across app restart | **PASS** |
| **TC-021** | Celebratory Popup (Passing Student) | `student01` passed all 6 subjects | Log in as `student01`, verify popup, then refresh/navigate to My Results | `#resultSuccessPopup` visible on first load, suppressed on subsequent navigation in same session | Shown once per session | **PASS** |
| **TC-022** | Celebratory Popup (Failing Student) | `student03` failed Mathematics (`28`) | Log in as `student03` | `#resultSuccessPopup` is NOT rendered; `#failedSubjectsAlert` highlights `Mathematics` | No popup shown; FAIL alert displayed | **PASS** |
| **TC-023** | Section Analytics Isolation | Students in Sections A, B, C | Compute `calculate_section_analytics` for Section A | Average percentage equals mean of Section A students only (`63.17%`), excluding B & C | Section A average `= 63.17%` | **PASS** |
| **TC-024** | Selenium E2E Teacher Journey | Live localhost server & Chrome | Execute 15-step teacher workflow (`test_complete_teacher_journey_e2e`) | Login, CRUD, marks entry, grade/classification check, analytics check, delete, logout all succeed | All 15 browser steps passed | **PASS** |
| **TC-025** | Selenium E2E Student Journey | Live localhost server & Chrome | Execute 14-step student workflow (`test_complete_student_journey_passing_and_failing_e2e`) | Passing & failing student verification, popup check, grading matrix check, `403` check, logout succeed | All 14 browser steps passed | **PASS** |
